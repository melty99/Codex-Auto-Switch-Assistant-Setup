# Codex 自动切换小助手

Save your sleep

版本：**v1.0**（插件版本 `1.0.0`）。由 **melty** 使用 **Codex** 开发。

[English](README.en.md) · [简明使用说明](QUICK_START.md) · [验证记录](VERIFICATION.md)

这是一个 Windows 本地工具，用于监测 Codex 订阅额度、通过 CC Switch 切换账号，并尝试继续由本工具暂停的本机聊天。附带中英文设置界面和按聊天保存的待执行任务队列。

**当前为本机测试版。** 已验证的功能和未完成的测试见文末；“继续任务”不等于保证所有任务、工具操作都能无损恢复。

## 快速开始

新设备请先准备好 Codex、CC Switch 及已登录的账号，将新设备安装包解压到固定目录，然后告诉 Codex：

> 文件目录在“XXX”，请根据该目录中“INSTALL_WITH_CODEX.md”的内容，安装并调试 Codex 自动切换小助手。

安装完成后，打开 CC Switch 的 **Codex** 供应商页面并选择 **不使用项目**，双击发布包最外层的 **setting.cmd**（或 **打开设置.cmd**），点击 **一键配置**。在 Codex 插件栏启用本插件，在助手设置中开启 **启用自动管理** 和 **额度恢复后自动继续被守护程序暂停的任务**，保存设置，再将右上角 **自动切换账号** 点成绿色。确认界面能读到当前额度、后台没有错误后即可使用；无需在每个聊天里重复调用 Skill。

已有安装直接打开设置即可；升级保留已有阈值和开关。更短的操作清单见 [简明使用说明](QUICK_START.md)。

## 运行条件

- Windows、官方商店版 Codex Desktop，以及支持本地插件安装的 Codex CLI。
- CC Switch 中已导入并登录的托管 ChatGPT 账号。自动换号需要至少两个账号；API key 和第三方模型供应商不在支持范围内。
- Python 3.11+（含 tkinter）和 Node.js 18+。优先使用 Codex 自带运行环境，本项目无需额外安装 pip/npm 依赖。
- Codex 与 CC Switch 使用同一个 Codex 配置目录；一键配置会检查目录和程序路径，缺失项需要手动补齐。

已验证的适配基线为 **Codex Desktop 26.924.2738.0、CC Switch 3.20.1 中文界面**。助手可以切换中英文，但这不代表已支持 CC Switch 的英文界面。

新设备安装包包含安装指南、本地插件市场、插件及唯一必需的内置 Skill；不包含应用安装程序、登录凭据或旧设备的聊天记录。安装后请保留解压目录，它是本地插件市场的来源。双击设置入口本身不等于完成插件安装。

## 日常使用

### 主界面

账号列表显示五小时和周剩余额度、读取时间及重置倒计时。五小时倒计时以小时表示，周倒计时以天表示，保留一位小数；`≈` 表示估算，`—` 表示缺失或查询失败，`待刷新` 表示上次估算已到期。缓存有单独标记，不应当作新的查询结果。

**手动切换账号** 按已保存规则选择其他可用账号，不要求右上角自动换号开关开启；但仍要求插件、自动管理和自动继续已开启。手动与自动换号共用同一流程：

1. 查询候选账号额度，并保存本工具暂停任务的记录。
2. 确认 Codex 正常退出。
3. 通过 CC Switch 启用目标账号，随后重新打开 Codex。
4. 核验当前账号额度和原聊天状态，继续符合条件的任务。

退出未确认或操作结果不明确时，流程停止并提示检查，不强制结束进程，也不盲目重复换号。界面显示“已安排”仅代表请求已提交，应以实际进度为准。

选号有两种方式，手动和自动换号共用：

- **综合额度优先**：按 `√(五小时剩余百分比 × 周剩余百分比)` 排序。它是本地排序分数，不代表可用 token 数。
- **自定义账号顺序**：读取 CC Switch 账号后，上移或下移调整优先级。

两种方式都跳过当前账号、五小时额度未超过恢复阈值、周额度耗尽或查询失败的账号。列表显示 `100% − 已用百分比`；实际选号额外保留 0.5 个百分点余量，以应对 CC Switch 百分比取整。

切换 VPN 后出现查询错误，可在网络稳定后点击 **刷新 CC Switch**。它重新查询各账号，失败时各重试一次，不切号、不重启 Codex。刷新使用后台控件调用，已实测最小化和隐藏状态下不抢前台焦点；若页面不可读，会提示手动检查，不自动唤起窗口。此功能不能修复 VPN 或无响应的 CC Switch。

### 设置与开关

| 控件 | 作用 |
| --- | --- |
| Codex 插件栏开关 | 控制本插件的后台自动操作；关闭后在下一次检查时生效 |
| 启用自动管理 | 助手内的独立总开关 |
| 额度恢复后自动继续被守护程序暂停的任务 | 控制原任务自动继续；换号流程也要求此项开启 |
| 自动切换账号 | 绿色为开启，灰色为关闭；点击立即保存 |
| 一键配置 | 检测并保存本机路径、检查配置目录、设置当前用户登录启动项 |
| English / 中文 | 切换助手界面语言 |

修改阈值、选号规则、动态监测或版本选项后，点击对应的 **保存设置**。等待区的两个勾选项立即保存。一键配置保留已有开关，不会替你开启被关闭的自动换号。

## 额度与恢复规则

当前账号的五小时剩余额度 **≤ 暂停阈值**，或周额度耗尽时，暂停符合条件的任务。恢复要求当前账号五小时剩余额度 **> 恢复阈值**，且周额度 **> 0**；换号后使用新账号的额度。额度缺失、过期或查询失败时不自动恢复。

新设备安装指南将暂停阈值设为 **5%**、恢复阈值设为 **10%**，并在验收后开启监测；自动换号仍默认关闭。直接使用程序基础默认值时，暂停阈值是 **1%**。两种安装方式都保留已有用户设置，实际行为以设置界面保存的值为准。

动态监测的默认间隔如下，分界和间隔均可修改：

| 当前账号五小时剩余额度 | 检查间隔 |
| --- | --- |
| ≥ 20% | 3 分钟 |
| ≥ 10% 且 < 20% | 1 分钟 |
| < 10% | 30 秒 |

达到暂停阈值、额度异常或核验恢复时，使用低额度检查间隔。关闭动态监测则使用固定间隔。监测是定期查询，不能保证在额度恰好跨过阈值的一瞬间停止；多个任务同时运行时，额度可能在两次查询之间迅速下降。

### 所有账号额度都不足时

开启等待重置后，程序在周额度仍可用的账号中选择已知五小时重置时间最早的账号，保存暂停记录并退出 Codex。后台持续查询额度：自然重置按核验的重置时间加 **5 分钟**安排重开；如提前发现额度恢复，需要连续两次达标后才提前重开。重开不代表立即发送继续指令，任务恢复仍需核验。

关闭 **额度恢复时自动重启任务** 会保留等待计划并继续监测，但不自动重开或继续；重新勾选后再次核验。关闭 **选择最早重置的账号…** 会取消等待计划。周额度也不足、重置时间不明确或查询失败时，不保证能安排自动重开。电脑关机或睡眠期间无法持续监测。

### 任务与恢复记录

只自动继续由本工具因额度不足暂停、且确认已停止的本机任务。手动停止、等待用户输入或审批、已被用户接管的任务不自动继续。恢复沿用原聊天、上下文和权限，不绕过审批；结果不明的发送转为“需检查”，不自动重发。

在 **任务与恢复记录** 中右键聊天，选择 **添加待执行任务…** 或 **管理待执行队列…**。队列等上一轮明确完成、聊天空闲且额度达标后，按顺序发送下一项；一次新额度查询达标即可，不需要连续两次。每次发送后重新检查额度。这里的“完成”指 Codex 报告该轮结束，不能证明任意文字目标已全部实现。

原任务恢复仍保留连续两次额度达标等检查，与队列发送规则不同。原生 Codex 待发送队列不为空、任务失败、手动中断或用户在聊天中另发内容时，助手会等待或暂停队列。可以删除待执行和已处理条目；发送中、执行中或结果不明的条目需先处理状态。删除队列条目不会删除原聊天消息。

## 兼容性与限制

- 版本跟踪检查本机版本和官方发布信息；接口检查通过时可沿用现有适配器。它不自动升级 Codex/CC Switch，也不会自动编写补丁；未来版本仍可能需要人工适配。
- 聊天控制依赖版本相关的本地内部接口，不是稳定公开 API。遇到未知协议或界面结构时停止相关操作。
- 已针对 Windows 虚拟桌面改进窗口定位，不移动窗口或切换桌面；完整跨桌面“退出、换号、重开、全部聊天恢复”尚未端到端验收。重开窗口所在桌面由 Windows 决定。
- 完整真实额度耗尽后的多聊天恢复仍未完成端到端验收。云任务、远程设备、锁屏及不同 Windows 用户会话不在当前支持范围内；外部工具操作不能保证撤销或无损接续。

已完成的测试范围见 [VERIFICATION.md](VERIFICATION.md)。单元测试或只读探测通过，不等于真实换号与全部任务恢复已经验证。

## 数据与维护

运行数据通常位于 Windows“文档”目录下的 `Codex/QuotaGuard`。该目录包含本机路径、设置、额度摘要和暂停记录；`task-queues.json` 还保存你输入的完整任务文本，属于本机明文数据。不要将此目录打包发布，也不要在仍有待恢复任务时删除记录。助手不自行复制或保存 OAuth 令牌，登录与账号配置由 Codex 和 CC Switch 管理。

插件显示名称为 **Codex Auto Switch Assistant**，内部标识为 `codex-quota-guard`。Skill 随插件安装，不必再复制到全局 Skill 目录。后台通过当前用户的 Windows 计划任务独立运行；关闭设置窗口不等于关闭监测。如需停止自动操作，请关闭插件或自动管理开关。

开发者可在插件目录执行：

```powershell
python -X utf8 -m unittest discover -s tests -p 'test_*.py'
node --test tests/bridge.test.cjs
```

界面测试可使用 `CODEX_QUOTA_GUARD_DATA` 指定隔离数据目录。不要把真实退出 Codex、切号或发送任务当作普通界面测试。
